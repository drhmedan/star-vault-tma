# 🌟 STAR VAULT TMA (خزنة النجوم)
> **أقوى لعبة تيليجرام ميني آب (Telegram Mini App) مدرّة لعائد سريع بنجوم تيليجرام (Telegram Stars - XTR)**  
> **مستودع المشروع:** [https://github.com/drhmedan/star-vault-tma](https://github.com/drhmedan/star-vault-tma)

---

## 🚀 نظرة عامة على المشروع (Project Overview)
**Star Vault TMA** هي لعبة تفاعلية سريعة ومصممة سيكولوجياً لتحقيق أعلى معدل إنفاق بنجوم تيليجرام الرسمية (`XTR`) بدون تعقيد محافظ الكريبتو أو رسوم الغاز، وتعتمد على بنية سحابية مجانية 100% (Vercel / Cloudflare + TiDB Serverless).

### 🎯 الميزات الرئيسية في اللعبة:
1. **خزائن وفتح الصناديق (Case Opening Roulette):**
   - أنيميشن أفقي دوار ومثير (بنمط CS:GO) لكشف الجوائز مع أصوات نقر ميكانيكية ووميض ندرة الجائزة.
   - 4 فئات من الخزائن: اليومية المجانية (كل 8 ساعات)، السايبر الفضية (🌟 25)، الذهبية (🌟 75)، والماس الأسود الأسطورية (🌟 250).
2. **معارك الصناديق التنافسية 1 ضد 1 (1v1 Case Battles):**
   - لاعبان يدخلان بنجوم متساوية لفتح نفس الصندوق معاً، وصاحب العنصر الأعلى ندرة يربح كلا العنصرين!
   - يدعم التحدي ضد لاعبين حقيقيين أو ضد بوتات محاكاة ذكية للبدء فوراً.
3. **عجلة الحظ الكبرى (The Lucky Star Wheel):**
   - عجلة دوارة 360 درجة بـ 8 قطاعات تحتوي على مضاعفات، سبائك، وجائزة كبرى تصل إلى **🌟 500 نجمة تيليجرام**.
   - لفة مجانية يومياً مع إمكانية شراء لفات VIP إضافية بـ 15 نجمة.
4. **متجر نجوم تيليجرام الرسمي (Official Telegram Stars Gateway):**
   - يدعم الشراء المباشر بنافذة تيليجرام الرسمية `Telegram.WebApp.openInvoice`.
   - باقات 50، 150، 500، و 1500 نجمة مع مكافآت مجانية إضافية.
   - روبوت التعدين التلقائي 24/7 لمدة 7 أيام.
5. **برنامج الإحالة الفيروسي 20% (Viral Affiliate Engine):**
   - رابط دعوة مخصص مع مشاركة فورية في تيليجرام.
   - 20% عمولة فورية بنجوم تيليجرام من أي مشتريات يجريها الأصدقاء المدعوون.
6. **حقيبة العتاد والبيع الفوري (Backpack & Instant Liquidate):**
   - فرز العناصر حسب الندرة (شائع، نادر، ملحمي، فريد، أسطوري).
   - إمكانية بيع أي عنصر فورياً لاسترداد نجوم تيليجرام أو غبار النجوم.

## 🛠️ البنية التقنية (Zero-Cost Tech Stack)
- **Frontend:** React 19, Vite, Tailwind CSS, DaisyUI, Lucide Icons, Canvas Confetti.
- **Audio:** Web Audio API (توليف إجرائي 100% بدون أي ملفات صوتية خارجية).
- **Backend:** Vercel / Cloudflare Serverless Functions (`/api/create-invoice`, `/api/telegram-webhook`).
- **Database:** TiDB Serverless (25GB تخزين مجاني + 50M طلب شهرياً مدى الحياة).

## 🌐 النشر المجاني الفوري (One-Click Deploy)
يمكنك ربط هذا المستودع مباشرة مع:
- **Vercel:** استيراد المستودع `drhmedan/star-vault-tma` وسيقوم Vercel ببنائه ونشره تلقائياً على رابط دائم `https://star-vault-tma.vercel.app`.
- **BotFather:** قم بإنشاء بوت جديد على `@BotFather`، وأضف رابط الميني آب عبر الأمر `/newapp`.
